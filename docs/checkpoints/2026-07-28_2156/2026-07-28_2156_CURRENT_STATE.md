## Product State

Lockdin is a Cambridge A-Level revision workspace platform designed to help students track their study progress across multiple subjects. The application currently provides:

- **Subject selection and management** for 9 Cambridge A-Level subjects (Mathematics, Physics, Chemistry, Biology, Computer Science, Economics, Business, History, Further Mathematics)
- **Syllabus tracking** with hierarchical structure (subjects → syllabus versions → units → topics → learning outcomes)
- **Task management** for revision planning with deadlines and priorities
- **Past paper logging** with atomic component/variant structure (Subject + Component + Variant + Session)
- **Exam date tracking** and calendar integration
- **Dashboard analytics** with progress visualization and gamification elements (XP, streaks)
- **Study planning** tools and calendar views

The application has a complete data infrastructure with a production-ready import pipeline. The database schema now supports syllabus versioning, assessment component atomization, and learning outcome normalization. The import pipeline can load all 9 subject syllabi with transactional safety and idempotent upserts.
